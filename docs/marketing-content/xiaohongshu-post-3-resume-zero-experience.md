# 小红书笔记 3：故事类

**封面文案**: 从简历石沉大海到一周3个面试🔥

---

**正文**:

双非本科、没有实习、简历投出去石沉大海。

这是3个月前的我。现在的我，拿到了offer。

最大的改变是什么？简历。

分享一下0实习经历的人怎么写简历，全是血的教训：

**1. 项目经历 > 实习经历**
没有实习？用课程项目、毕业设计、自学的项目代替。关键不是"在哪做的"，而是"做成了什么"。
✅ "用Python爬取5000条招聘数据，分析岗位需求分布"
比"在校期间学习Python"强100倍。

**2. 技能用场景说话**
不要写"熟练Office"——这等于什么都没写。
✅ "用Excel做2000行销售数据分析，生成自动化报表模板供团队使用"

**3. 自我评价是必杀技**
应届生的自我评价不是废话区。写你的职业目标+核心优势。
✅ "电商运营方向应届生，自学SEO/SEM实操，运营过2个小红书账号累计1万粉丝"

**4. 格式！格式！格式！**
PDF！PDF！PDF！重要的事说三遍。Word在不同设备上打开排版全乱。
