## 4. OAuth 功能开发计划

### 4.1 技术架构

```
┌─────────────────────────────────────────┐
│          HarmonyOS Application          │
├─────────────────────────────────────────┤
│  UI Layer (LoginPage.cj)                │
│  ├─ WeChat Login Button                 │
│  └─ Alipay Login Button                 │
├─────────────────────────────────────────┤
│  Service Layer                          │
│  ├─ WeChatAuthService.cj                │
│  ├─ AlipayAuthService.cj                │
│  └─ TokenManager.cj                     │
├─────────────────────────────────────────┤
│  Third-party SDK                        │
│  ├─ WeChat SDK                          │
│  └─ Alipay SDK                          │
└─────────────────────────────────────────┘
           ↕ OAuth 2.0
┌─────────────────────────────────────────┐
│         Backend API Server              │
├─────────────────────────────────────────┤
│  POST /api/auth/wechat/login            │
│  POST /api/auth/alipay/login            │
│  POST /api/auth/refresh                 │
└─────────────────────────────────────────┘
```

### 4.2 数据流设计

```
用户点击登录
    ↓
调用微信/支付宝 SDK
    ↓
跳转到授权页面
    ↓
用户确认授权
    ↓
接收授权回调
    ↓
发送授权码到后端
    ↓
后端验证并创建用户
    ↓
返回 JWT Token
    ↓
存储 Token 到本地
    ↓
跳转到主页
```

### 4.3 文件结构

```
entry/src/main/cj/
├── services/
│   ├── WeChatAuthService.cj         # 微信登录服务
│   ├── AlipayAuthService.cj         # 支付宝登录服务
│   └── TokenManager.cj              # Token 管理器
├── utils/
│   ├── OAuthHelper.cj               # OAuth 工具类
│   └── CryptoUtils.cj               # 加密工具
├── models/
│   └── OAuthUser.cj                 # OAuth 用户模型
└── views/
    ├── UnifiedLoginPage.cj          # 统一登录页面
    └── OAuthBindingPage.cj          # 账号绑定页面
```
