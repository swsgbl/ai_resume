为鸿蒙开发而生的完整工具面

34 个智能体工具覆盖「创建 → 构建 → 签名 → 装机 → 日志 → 质量门禁 → 生态雷达」全链路,DevEco Studio 的命令行等价物,由 AI 自主编排。

🏗️

工程脚手架

harmony_project_create 一句话生成完整 Stage 模型工程(AppScope / entry / hvigor / oh-package / 测试),自动装配 DevEco 调试签名。

🔨

HAP 命令行构建

harmony_build_hap 走 DevEco 同款链路(ohpm + hvigorw),秒级出包,失败自动解析典型构建错误。

📲

装机运行

harmony_run:签名检查 → hdc install → aa start → hilog 跟随。模拟器实测全通,真机链即插即用。

👁️

视觉看图

harmony_see_image 让纯文本主模型按需调视觉端点看图 —— 截图、报错弹窗、设计稿,零路由切换。

📐

工程质量门禁

harmony_lint 包装华为官方 codelinter(baseline 增量治理,存量债务不阻断)+ 项目画像 + UI 视觉回归(harmony_visual_check),质量评分自动计入基准循环。

🧠

自进化

跨会话记忆自动注入系统提示词;技能草稿 → 静态审查 → 人工批准晋升;基准评测 + git 快照,严格提升才保留。

📡

控制论事件域

感知(harmony_sense)→ 世界模型(harmony_world_model)→ 决策 → 执行 → 反馈,五环闭环的可观测开发回路。

🛡️

安全门禁

deny-first 设备命令门禁:安装 / 卸载 / 清数据 / 重启类命令默认拒绝;技能晋升必过 Misevolution 静态审查 + 人工批准。

🛰️

生态雷达(hm 管家)

8 源全景开源鸿蒙雷达(不止华为:PMC/SIG 周会·RFC·71 个 SIG·核心仓脉搏·开放原子基金会)每日 diff 脚手架与门禁假设,变更简报由本地 FreeRide 免费模型网关生成;P2 issue 管家每日拉取社区 issue 分类起草回复,人批准后才发布(双重门禁+AI 标识);修复流出方案卡→主模型修复→人批开草稿 PR;雷达与社区洞察自动沉淀进进化记忆——零成本自运维。

三步上手

Windows 一键安装;前置(Node ≥ 22 / pnpm / Git / dsh / DevEco Studio)详见 INSTALL 文档,各环节官方直达链接齐备。

1
克隆仓库
git clone https://github.com/swsgbl/harmony-harness.git
cd harmony-harness
2
一键总装(幂等:前置检查 → 构建 → hvigorw 铺路 → profile → preset → hm 命令 → 品牌)
pwsh -NoProfile -ExecutionPolicy Bypass -File scripts/install.ps1
3
选模型路由,启动
hm model set glm-coding     # 或 kimi / qwen / deepseek / ollama …
hm tui
