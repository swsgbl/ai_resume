# Design Context — ndtool.cn

## Brand

**Product**: ndtool.cn — AI Resume Builder + Career Intelligence + Resource Tools
**Tagline**: 智能职业工具站
**Market**: Chinese tech professionals seeking career development

## Audience

**Primary**: Chinese software engineers, 25-40 years old, seeking new job opportunities or career advancement. They are practical, time-conscious, and value substance over flash. They've seen enough generic landing pages to be skeptical of marketing language.

**Secondary**: Recruiters and hiring managers evaluating AI-generated resumes.

**State of mind**: Purposeful, slightly anxious about career moves, looking for tools that actually work — not pretty distractions.

## Aesthetic Direction

**Core feeling**: Ink-and-paper meets precision engineering. A calligrapher's restraint with an architect's grid. Not "tech startup" — think "digital atelier."

**Metaphor**: A well-organized desk in a traditional Chinese study — clean surfaces, deliberate placement, quality materials, nothing unnecessary.

**Anti-directions** (what this is NOT):
- Generic dark mode with neon gradients
- Card grids on card grids
- Glassmorphism soup
- Purple-blue gradient hero sections
- Rounded everything with drop shadows
- Emoji-heavy interfaces
- "AI-generated" look (uniform spacing, predictable layouts)

## Color System

**Background**: Warm off-black `#0C0C0C` with subtle warm undertone (not blue-black)
**Surface**: `#161616` — elevated cards and containers
**Border**: `#252525` — barely visible structure lines

**Primary accent**: Vermillion `#C84B31` — derived from traditional Chinese seal paste (印泥). Used sparingly for CTAs, active states, and key actions. Not a red — a warm, confident vermillion.

**Secondary accent**: Celadon `#8FAE8B` — muted jade green for secondary actions, success states, and supporting information. Calm and trustworthy.

**Text hierarchy**:
- Primary: `#E8E4DE` — warm off-white (not pure white)
- Secondary: `#8A8580` — warm gray
- Muted: `#5A5652` — deep warm gray

## Typography

**Headings**: "Noto Serif SC" (serif) — Chinese-optimized serif with literary gravitas. Not the typical sans-serif tech look. For English headings, fall back to "Playfair Display".

**Body**: "Noto Sans SC" — clean, readable Chinese sans-serif. For English, "DM Sans" remains.

**Monospace**: "JetBrains Mono" for code and technical data.

**Scale**: Fluid typography with Chinese text optimization — larger line-height (1.8 for Chinese body text), wider letter-spacing for headings.

## Layout Principles

1. **Breathing room over density** — Generous whitespace, especially on landing pages
2. **Asymmetric grids** — Break the predictable 3-column pattern. Use editorial layouts with varying column widths
3. **Single focal point per section** — Each section has ONE thing that draws the eye
4. **Scroll as narrative** — The page tells a story, not a catalog
5. **Chinese reading rhythm** — Respect the natural reading flow of Chinese text blocks

## Component Language

**Cards**: Minimal borders, subtle background elevation. No rounded-corner-everything — use sharp corners with occasional 4px radius for softness where appropriate.

**Buttons**: Solid fills with the vermillion accent. No gradients. Hover: slight darkening. Active: press-down feel. Text-only ghost buttons for secondary actions.

**Navigation**: Clean horizontal bar. Fixed, minimal. Active state: underline in vermillion. No background color changes.

**Forms**: Clean, spacious inputs with bottom-border-only style. Labels above, not inside.

**Icons**: Line-style, 20px stroke width. No filled icons. No emoji as icons.

## Motion

**Philosophy**: Calligraphy — deliberate, flowing, never mechanical.

- Page transitions: Fade + slight upward drift (20px)
- Hover: Subtle scale (1.02) + shadow increase
- Loading: A single ink-drop animation, not spinning circles
- Scroll reveals: Staggered, not simultaneous
- Duration: 300ms for interactions, 500ms for page transitions

## Responsive Strategy

- **Mobile (< 768px)**: Single column, larger touch targets (48px), bottom-sheet navigation
- **Tablet (768-1024px)**: Two-column layouts, collapsible sidebar
- **Desktop (> 1024px)**: Full editorial layouts, hover states enabled

## Accessibility

- Color contrast: Minimum 4.5:1 for all text
- Focus states: Visible rings in vermillion
- Reduced motion: Respect `prefers-reduced-motion`
- Keyboard navigation: Full tab order support

## Polanyi Tacit Knowledge Integration

The career intelligence features should feel like consulting a wise mentor, not filling out a form. UI should:
- Use conversational prompts, not form fields where possible
- Show "intuition" before "analysis" (gut feeling first, data second)
- Animate results appearing as if the AI is "thinking" — not instantly
- Use warm, human language — not clinical AI terminology

## Reference Sites (aspiration, not copy)

- Linear.app — restraint and precision
- Vercel.com — confidence in whitespace
- Readwise.com — content-first, tools-second
- 传统中式排版 — vertical rhythm, breathing room
